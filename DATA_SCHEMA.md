# Xbox2PC — Sanitized Public JSON Data Schemas

All public datasets are generated by `xbox2pc.core.public_exporter` and validated against strict Pydantic schemas defined in `xbox2pc.core.public_schema`.

Every schema enforces `extra="forbid"`. Any field not explicitly whitelisted causes immediate schema rejection.
